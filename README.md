# Energy Demand Forecasting — Germany, day-ahead

Hourly day-ahead forecasts of German electricity demand (2015 – Sep 2020) from public data,
issued at the same time as the TSOs' official forecast (09:00 UTC on D-1). Compares naive
baselines, the official forecast, Ridge and LightGBM models in a monthly rolling-origin
backtest, with realistic weather-forecast noise, significance tests, prediction intervals and
SHAP explanations.

**→ Full write-up: [`reports/REPORT.md`](reports/REPORT.md)** · End-to-end notebook:
[`notebooks/03_end_to_end.ipynb`](notebooks/03_end_to_end.ipynb)

## Results at a glance (day-ahead MAE, GW)

| | 2019 | Jan–Sep 2020 |
|---|---|---|
| Official TSO forecast | 1.99 | 1.46 |
| TSO forecast, bias-corrected | 1.55 | 1.30 |
| **LightGBM ensemble (realistic weather)** | **1.00** | **1.06** |

Half the official forecast's error in 2019, all differences significant (Diebold-Mariano
p < 0.001); calibrated 80 % intervals with 79–81 % coverage. Details, caveats and next steps in the
report.

## Reproduce
```bash
uv sync                      # Python 3.12 environment from uv.lock
uv run fetch-data            # download OPSD + Open-Meteo (~140 MB) and build data/interim/
uv run run-backtest          # 11 backtests with cached tuned params (~2.2 h on a laptop); --tune re-tunes (hours)
uv run run-backtest --metrics-only  # recompute intervals + metrics from saved predictions (seconds)
uv run pytest                # tests (leakage, backtest windows, metrics, holidays, DST)
uv run jupyter lab           # notebooks/01_eda, 02_baselines, 03_end_to_end
```
macOS: LightGBM needs OpenMP (`brew install libomp`). Notebooks are generated by
`notebooks/_make_*.py` and executed with
`uv run jupyter nbconvert --to notebook --execute --inplace notebooks/<name>.ipynb`.

## Data
Re-fetch everything with `uv run fetch-data` (add `--force` to re-download). Retrieved 2026-11-07.

| Dataset | Source | Coverage | License / terms |
|---|---|---|---|
| OPSD Time series, 60-min single-index (release 2020-10-06, final release) | https://data.open-power-system-data.org/time_series/2020-10-06/ | 2015-01-01 – 2020-09-30, hourly, UTC | Compiled from ENTSO-E Transparency and TSO data; licensing follows the original sources (see `data/raw/opsd/datapackage.json`). Cite: *Open Power System Data. 2020. Data Package Time series. Version 2020-10-06.* |
| Open-Meteo Historical Weather API (ERA5-based reanalysis) | https://archive-api.open-meteo.com/v1/archive | Same period, hourly, 5 German cities | CC BY 4.0 — attribution to Open-Meteo.com |

**Target:** `DE_load_actual_entsoe_transparency` (Germany total load, MW).
**Benchmark:** `DE_load_forecast_entsoe_transparency`, the TSOs' official day-ahead forecast.
**Weather features:** temperature, humidity, wind, cloud cover and shortwave radiation, averaged over
Berlin, Hamburg, Munich, Cologne and Frankfurt, weighted by population (`w_*` columns), plus per-city temperature.

Interim outputs (`data/interim/`): `de_load.parquet`, `de_weather.parquet`, both 50,400 hourly rows on the same UTC index.
